# Abinaya Nehru Portfolio

## Run in VS Code or Antigravity
1. Extract this ZIP.
2. Open the `abinaya-portfolio` folder in VS Code/Antigravity.
3. Install Node.js LTS if it is not already installed.
4. Open a terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Resume
Put your actual PDF at `public/resume.pdf`. The contact section links to that path.

## Before publishing
Review the project descriptions and skill list in `src/data.ts` to ensure every listed tool/description accurately reflects your own work. Private projects intentionally have no fabricated repository URLs.
